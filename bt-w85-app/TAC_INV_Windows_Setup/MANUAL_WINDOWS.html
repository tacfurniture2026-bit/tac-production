📠 TAC 棚卸業務アプリ (BT-W85 / BT-H10W) Windows かんたん設定・運用マニュアル

本パッケージは KEYENCE「BT開発・運用ツール (BT Application Design Tool v2.3.3.0)」 用に画面設計・データ出力設定を100%作り込み済みの完成パッケージです。
お客様側で画面の部品配置やコード作成を行う必要は一切ありません。以下の3ステップ（設定のみ）ですぐに運用を開始できます。

STEP 1：Windows PC への自動セットアップとハンディへの転送（初回のみ）

手順 1-1
解凍したフォルダ内にある 1_SETUP_BT_TOOL.bat をダブルクリックします。
  • 自動的に Windows の ドキュメント\KEYENCE\BT Application Design Tool\Projects\TAC_INV に完成済みアプリ（7ファイル）が配置されます。
  • デスクトップに TAC_HT棚卸データ フォルダが作成され、商品マスタ（MasterFile_1.csv）と担当者マスタ（USERS.CSV）が自動保存されます。
  • そのまま自動的に KEYENCE「BT開発・運用ツール」 が立ち上がり、完成済みの TAC_INV プロジェクトが開きます。
手順 1-2
BT-W85（ハンディ本体）を通信ユニット（BT-H10W）に置くか、USBケーブルで Windows PC に接続します。
起動した「BT開発・運用ツール」の画面上部（ツールバー）にある以下のボタンを順番にクリックします：
  1. ［HTへ転送］（または［端末へ送信］／ハンディのアイコン） をクリック ➔ ハンディ本体に「棚卸スキャン」アプリが書き込まれます。
  2. ［PCアプリケーション起動］（パソコンのアイコン） をクリック ➔ Windows PC 側に「TAC 棚卸データ受信アプリ」のウィンドウが立ち上がります（データ受信待ち状態になります）。
💡 よくあるご質問：「マスタファイル設定」の操作は必要ですか？
不要です！ 現在のアプリ設計では、生産管理システムから印刷した「品名QRコード」自体に『資材CD』と『品名』が入っており、スキャンするだけでハンディ画面に資材CDと品名が表示されます。
また、従来から棚に貼ってある『資材CDのみ』のQRコードをスキャンした場合も、PCの生産管理システムへCSVを取り込んだ瞬間にシステム内の商品マスタ（1,194件）と自動照合されて品名・単価がすべて自動反映されます。

STEP 2：BT-W85（ハンディ本体）での棚卸スキャン操作

棚卸スキャン
担当 admin (管理者)
資材QR (資材CD / 品名)
1121 ﾎﾜｲﾄｱｯｼｭ 24×125
数量 15
F1:ログアウト
F2:送信
F3:履歴
F4:確定
  1. メニュー選択：ハンディ画面の 1. 棚卸スキャン を選択します。
  2. 担当者ログイン（最初の1回のみ）：1番上の 担当 欄にカーソルがあるので、「担当者ログインQR」をスキャン（または担当者IDを入力して ENT）します。
    ※一度入力すると、[F1] ログアウト を押すまで同じ担当者がずっと保持・表示され続けます（1回ごとに担当を入力する必要はありません）。
  3. 資材QRスキャン：2段目の 資材QR (資材CD / 品名) 欄で資材QRをスキャンします。
    ※同じ資材QRを連続で二度読みすると、警告ブザー＆赤LEDでダブりを防止します。
  4. 数量入力＆確定ループ：3段目の 数量 欄に実棚数量を入力し、ENT キー（または [F4] 確定）を押します。
    ※即座に保存され、上部の「担当」は残ったまま、自動的に次の「資材QR」入力待ち（新規入力画面）に戻ります！
  5. 履歴確認・修正：[F3] 履歴 を押すと、ハンディ上でスキャン済みデータの確認・削除ができます。

STEP 3：Windows PC へのデータ送信 ＆ 生産管理システムへの一括取込

手順 3-1：ハンディからPCへ送信
スキャンが終わったら、BT-W85 を通信ユニット（BT-H10W）に置き、ハンディの [F2] 送信 キーを押します。
PC側の「TAC 棚卸データ受信アプリ」にデータが転送され、Record.csv が保存されます。
手順 3-2：Record.csv をデスクトップに集める
フォルダ内の 2_GET_RECORD_CSV.bat をダブルクリックします。
Windows 内に保存された最新の Record.csv を全自動で見つけ出し、デスクトップの TAC_HT棚卸データ フォルダにコピーして開きます。
手順 3-3：生産管理システム（Web）へ取り込む
3_OPEN_WEB_SYSTEM.bat をダブルクリックして生産管理システムを開き、「▦ 棚卸スキャン」または「☑ 棚卸スキャン確認」➔「📠 HTデータ取り込み (BT-W85)」をクリックして、デスクトップの TAC_HT棚卸データ\Record.csv を選択します。
  • スキャン実行者（担当者）が自動認識されます。
  • 重複（ダブり）スキャンがある場合は赤い警告バナーが表示され、「➕ 数量を合算する」または「✍️ 上書き修正する」を選んでワンクリックで棚卸仮登録へ反映できます！
