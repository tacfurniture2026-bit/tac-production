# KEYENCE BT-W85 / BT-H10W 棚卸スキャンアプリ（v2.0：担当者ログイン・HT担当者増減・重複アラート対応）開発・取込完全マニュアル

本マニュアルでは、ハンディターミナル **KEYENCE BT-W85** およびアプリケーション開発ソフト **BT-H10W (BT-Navigator)** を使用して、生産管理システムと完全連携する「棚卸スキャン専用アプリ（v2.0）」を構築・転送し、スキャンしたCSVデータを生産管理システムへバッチ取り込みするまでの全手順を解説します。

---

## 🆕 v2.0 アップグレード内容（今回の改良点）

1. **ユーザー管理連携・ログイン管理（誰がスキャンしたか記録・表示）**
   - 生産管理システムの「👥 ユーザー管理」に登録されている **`username`（ログインID）** と **`displayName`（表示名・氏名）** を `USERS.CSV` として出力し、BT-W85起動時に**担当者ログイン**を行います。
   - システムの「📋 棚卸スキャン確認」画面の **「スキャン実行者 (ログインID)」欄** に、`山田 太郎 (yamada)` のように表示名とログインIDが正確に記録・表示されます。
   - ユーザー管理画面から **「🪪 担当者ログインQR一覧印刷」** も可能で、名札QRをスキャンして一瞬でログインすることもできます。
2. **BT-W85ハンディ機本体での担当者追加・削除（増減管理）と双方向同期**
   - BT-W85のログイン画面で **`[F2]追加`** を押すと新しい担当者をハンディ上で直接追加でき、**`[F3]削除`** を押すと既存担当者を削除できます（端末内の `USERS.CSV` を直接更新）。
   - ハンディ側で追加・削除した `USERS.CSV` を生産管理システムのユーザー管理画面（「🔄 HT変更分(USERS.CSV)をシステムへ同期」）に取り込むことで、システムのユーザー管理へ逆同期することも可能です。
3. **システム発行QRコード読み取り ＆ 重複（ダブり）スキャン時のアラート機能**
   - システムから発行した資材QRコード（`INV:資材ID` 形式・生ID形式の両対応）を読み取り登録します。
   - 同一資材を再度スキャンした場合、通常の棚卸スキャンと同様に **警告ブザー＋赤LED点滅＋重複アラート画面** が立ち上がり、以下の3つから選択できます：
     - **`[1] ➕追加(合算)する`**（前回数量 ＋ 今回数量）
     - **`[2] ✍️上書き修正`**（今回数量で上書き）
     - **`[3] ❌キャンセル`**（今回のスキャンを取り消す）
   - PC・スマホでのHTデータ取り込み時にも、既にシステム側で当月スキャン済みの資材とダブりがある場合は**重複検知バナー**で警告し、「上書き」または「合算（加算）」を選択して取り込めます。

## 🛠️ 2. BT-H10W でのアプリ設定・ビルド手順（初回のみ）

BT-W85には、GUI設定ソフト **「BT-H10W (BT-Navigator)」** またはスクリプトコンパイラを使用してアプリを転送します。

### 方法A：BT-H10W（GUI画面）で設定する場合（推奨・一番簡単）

1. PCで **BT-H10W** を起動し、**「新規作成」** をクリックします。
   - **機種選択**：`BT-W80 / BT-W85 シリーズ` を選択
   - **アプリ名**：`TAC棚卸スキャン`
2. **「マスタファイル設定」**：
   - **マスタ1（商品マスタ）**：ファイル名 `MASTER.CSV`、区切り文字 `カンマ(,)`
     - フィールド1：`資材ID`（最大32桁 / キー項目）
     - フィールド2：`品名`（最大64桁）
     - フィールド3：`型番・仕様`（最大64桁）
     - フィールド4：`分類`（最大32桁）
     - フィールド5：`単位`（最大16桁）
     - フィールド6：`棚番`（最大32桁）
   - **マスタ2（担当者マスタ）**：ファイル名 `USERS.CSV`、区切り文字 `カンマ(,)`
     - フィールド1：`username`（ログインID・最大32桁 / キー項目）
     - フィールド2：`displayName`（表示名・最大64桁）
     - フィールド3：`department`（部署・最大32桁）
   - ※ または、同梱の [`HTMasterFileInfo.ini`](file:///Users/shinobu/Desktop/development/production-management-simple/bt-w85-app/HTMasterFileInfo.ini) をBT-H10Wのプロジェクトフォルダに上書きコピーすると自動反映されます。
3. **「業務メニュー設定（メインメニュー）」**：
   - 起動直後に **「担当者ログイン画面」**（`USERS.CSV` 参照または担当者QRスキャン、F2で担当者追加、F3で担当者削除）を表示し、ログイン後に **「1: 棚卸スキャン」** メニューへ進むように設定します。
   - 高度なカスタマイズ（重複時の `[1]合算 / [2]上書き / [3]キャンセル` 分岐や担当者追加・削除処理）をそのまま使う場合は、同梱の [`TAC_TANAOROSHI.scp`](file:///Users/shinobu/Desktop/development/production-management-simple/bt-w85-app/TAC_TANAOROSHI.scp) をスクリプトプロジェクトとして読み込み、ビルドしてください。
4. **ログ出力ファイル設定（`INV_LOG.CSV`）**：
   - 出力ファイル名：`INV_LOG.CSV`
   - 出力項目（7列）：
     1. `日付` (`YYYY/MM/DD`)
     2. `時刻` (`HH:MM:SS`)
     3. `端末ID` (`BT-W85` 等)
     4. `ログインID (username)`
     5. `表示名 (displayName)`
     6. `資材ID` (システムQR `INV:xxx` の場合は自動で `xxx` に整形)
     7. `棚卸数量`
5. **実機へのアプリ転送**：
   - BT-W85を通信クレードル（USB接続）にセットし、BT-H10W画面右上の **「端末へ送信」** ボタンを押します。

## 📦 3. 毎月の棚卸しの運用フロー（4ステップ）

```mermaid
flowchart LR
    A["① システムから<br/>MASTER.CSV と USERS.CSV 出力"] --> B["② BT-W85へ転送し<br/>担当者ログイン＆棚卸スキャン"]
    B --> C["③ BT-W85をPCに繋ぎ<br/>INV_LOG.CSV を回収"]
    C --> D["④ 生産管理システムの<br/>『📟 HTデータ取込』へ投入"]
```

### ステップ①：生産管理システムからマスタ（商品・担当者）を出力する
1. **商品マスタの出力**：
   - 「📋 棚卸スキャン確認」または「📱 棚卸スキャン」画面の **「📟 HTデータ取込 (BT-W85)」** ボタン（または商品マスタ画面の **「📤 HT用マスタ出力(BT-W85)」** ボタン）をクリックし、`MASTER.CSV` をダウンロードします。
2. **担当者マスタ（ログイン用）の出力**：
   - 「👥 ユーザー管理」画面（またはHTデータ取込モーダル内）の **「📤 HT用担当者マスタ出力 (USERS.CSV)」** ボタンをクリックし、`USERS.CSV` をダウンロードします。
   - 💡 **便利機能**：「👥 ユーザー管理」画面の **「🪪 担当者ログインQR一覧印刷」** をクリックすると、各担当者のログイン用QRコード一覧を印刷できます。

### ステップ②：BT-W85で担当者ログイン＆棚卸スキャンを行う
1. ダウンロードした `MASTER.CSV` と `USERS.CSV` を、通信ソフト（BT-H10W Data Transfer / Web転送）で BT-W85 のドライブへコピーします。
2. BT-W85 の電源を入れると **「【担当者ログイン】」画面** が表示されます：
   - **番号選択ログイン**：画面に表示されている担当者（`[1] 山田 太郎 (yamada)` など）の数字キーを押してログインします（`[4]` / `[6]` キーでページめくり）。
   - **QRスキャンログイン**：印刷した担当者QRコード（`USER:yamada:山田 太郎`）をトリガーでスキャンすると一発でログインできます。
   - **HTでの担当者追加（`[F2]追加`）**：ハンディ上でログインIDと表示名を入力（または名札スキャン）して、その場で担当者を `USERS.CSV` に追加できます。
   - **HTでの担当者削除（`[F3]削除`）**：一覧から対象の番号を選択して、`USERS.CSV` から担当者を削除できます。
3. メインメニューで **`[1] 棚卸スキャン開始`** を押します（画面上部にログイン中の担当者名が表示されます。`[F4]` で途中交代も可能）。
4. 現場の資材QRコード（システム発行の `INV:資材ID` またはバーコード）をスキャンします。
   - マスタ未登録のコードを読んだ場合は警告音が鳴り、誤登録を防止します（強制登録も選択可）。
5. **数量を入力して `ENT` キー** を押します。
6. **同じ資材を2回スキャンした場合（重複ダブりアラート）**：
   - 警告ブザーと赤LEDが点滅し、**`⚠️ スキャン重複(ダブり)!`** 画面が表示されます。
   - 前回数量と今回数量を見比べて、**`[1] ➕追加(合算)する`** / **`[2] ✍️上書き修正`** / **`[3] ❌キャンセル`** のいずれかを数字キーで選択します。

### ステップ③：BT-W85からスキャン実績（`INV_LOG.CSV`）をPCへ回収する
1. 棚卸スキャンが終わったら、BT-W85をクレードルに置きます。
2. PC上に保存された **`INV_LOG.CSV`**（また、HT上で担当者を追加・削除した場合は **`USERS.CSV`**）を取り出します。

### ステップ④：生産管理システムへバッチ取り込みする
1. 生産管理システムの「📋 棚卸スキャン確認」画面（または「📱 棚卸スキャン」画面）にある **「📟 HTデータ取込 (BT-W85)」** ボタンをクリックします。
2. **「① 対象棚卸月」** を確認します。
3. **「② スキャン実行者（フォールバック設定）」**：
   - CSV内に担当者情報（`username` / `displayName`）が記録されているため、基本的には **「CSV内の担当者情報を優先」** のままで自動的に誰がスキャンしたか反映されます。
   - 万一CSVに担当者名がない場合や、全員分を特定ユーザーに統一したい場合のみプルダウンで選択します。
4. **「③ 重複データ（ダブり）の扱い」**：
   - 既にシステム側で当月スキャン済みの資材とダブりがある場合、画面中央に **「⚠️ 既存スキャンデータとの重複（ダブり）が X 件あります！」** と警告バナーが表示されます。
   - 「最新値で上書き（推奨）」または「数量を合算（加算）」を選択できます。
5. **`INV_LOG.CSV` をドラッグ＆ドロップ** するとプレビュー一覧（資材ID・品名・今回数量・既存数量・スキャン実行者・状態バッジ）が表示されます。
6. **「📥 この内容で仮スキャンへ一括登録する」** をクリックすると取り込み完了です！「📋 棚卸スキャン確認」画面の **「スキャン実行者 (ログインID)」列** に担当者の表示名とログインIDが表示されます。
